# Performance Review Agent

## Purpose
The Performance Review Agent automates the employee performance management cycle. It tracks goals throughout the year, collects 360-degree feedback, conducts structured reviews, creates development plans, and provides data for compensation decisions. It replaces ad-hoc reviews with systematic, fair, continuous feedback.

Ideal for scaling teams, ensuring fair evaluations, retaining top talent, and developing future leaders.

## Capabilities
- **Goal Setting**: OKR framework, quarterly goal setting, progress tracking
- **Feedback Collection**: 360-degree feedback (manager, peers, direct reports)
- **Sentiment Analysis**: Identify themes in feedback (strengths, development areas)
- **Performance Scoring**: Consistent rating system (1-5 scale)
- **Calibration**: Compare ratings across team (ensure consistency)
- **Development Plans**: Growth areas, learning opportunities, mentors
- **Compensation Analysis**: Link performance to raises, bonus, equity
- **Retention Prediction**: Identify flight risks (dissatisfied high performers)

## Workflow

1. **Goal Setting Phase** (Jan-Feb)
   - Define company OKRs (strategic priorities)
   - Cascade to team goals
   - Individual goals (5-7 goals, aligned to team/company)
   - Document success criteria (how to know goal achieved)
   - Quarterly check-ins (progress, any adjustments)

2. **Continuous Feedback Phase** (Jan-Dec, ongoing)
   - 1-on-1 meetings (weekly, manager provides feedback)
   - Peer feedback (monthly, teammates provide input)
   - Self-assessment (employee tracks accomplishments)
   - Incident logging (track both successes and failures)

3. **Feedback Collection Phase** (Nov)
   - Send 360 survey to manager, peers, direct reports (if manager)
   - Questions cover: strengths, growth areas, collaboration, impact
   - Anonymous responses (encourages honesty)
   - Response rate: Target 80%+ participation

4. **Review Preparation Phase** (Nov-Dec)
   - Compile all feedback
   - Summarize themes (what's repeated across reviewers?)
   - Score performance (1-5 scale, based on goals + feedback)
   - Prepare review document
   - Calibrate with other managers (ensure consistency)

5. **Review Meeting Phase** (Dec)
   - 1-hour review meeting
   - Manager shares feedback (strengths + growth areas)
   - Employee responds (context, self-assessment)
   - Discuss rating and what it means
   - Plan next steps (development plan, compensation, role)

6. **Development Plan Creation Phase** (Dec-Jan)
   - Identify growth areas (where should they improve?)
   - Define learning opportunities (courses, mentors, projects)
   - Set development goals (SMART goals for growth)
   - Check-in cadence (quarterly progress reviews)
   - Resource allocation (budget for training if needed)

7. **Compensation Adjustment Phase** (Jan)
   - Use performance score + market data to adjust salary
   - Bonus payout (based on goal achievement)
   - Equity grant (for high performers, key roles)
   - Communicate decisions clearly
   - Manage expectations (why this adjustment)

8. **Retention & Succession Phase** (Ongoing)
   - Identify high performers (potential for promotion)
   - Identify flight risks (might leave soon)
   - Create retention plans (career growth, interesting projects)
   - Build succession pipeline (groom next leaders)

## Input Requirements
- **Company OKRs**: Strategic priorities for the year
- **Team Goals**: What each department is focused on
- **Review Calendar**: When reviews happen (monthly, quarterly, annually)
- **Rating Scale**: How to rate performance (1-5, 1-4, etc.)
- **Compensation Budget**: How much for raises/bonuses
- **Retention Data**: Who's leaving? Why?

## Configuration
- **Review Frequency**: Annual, biannual (default: annual)
- **Rating Scale**: 1-5 or 1-4 (default: 1-5)
- **360 Feedback**: Required, optional (default: required for managers)
- **Development Planning**: Yes/no (default: yes)

## Best Practices
1. **Continuous Feedback**: Don't save all feedback for annual review
2. **Clear Goals**: SMART goals, not vague aspirations
3. **Objective Data**: Feedback should be based on observable behavior
4. **Consistency**: Use same rating criteria across team
5. **Growth Focus**: Frame reviews as development opportunity, not judgment
6. **Transparency**: Share rubric, explain ratings clearly
7. **Two-Way Dialogue**: Reviews are conversations, not top-down judgments

## Edge Cases
- **High Performer, Low Engagement**: May be disengaged (flight risk)
- **Good Person, Below Expectations**: Need development plan or performance plan
- **New Hire Year 1**: Shorter evaluation period, focus on integration
- **Remote Employee**: May receive different feedback (visibility bias)
