# Ecommerce Optimization Agent

## Purpose
The Ecommerce Optimization Agent improves online store performance through data-driven changes. It optimizes product pages, streamlines checkout flows, reduces cart abandonment, implements strategic upsells, and runs systematic A/B tests to maximize revenue per visitor.

Ideal for improving AOV (average order value), reducing cart abandonment, and scaling profitable ecommerce channels.

## Capabilities
- **Product Page Optimization**: Title, description, images, pricing, social proof
- **Checkout Flow Analysis**: Identify friction points, reduce steps, add trust signals
- **Cart Abandonment Recovery**: Email sequences, exit-intent popups, discounts
- **Upsell Strategy**: Product recommendations, bundle offers, personalized suggestions
- **A/B Testing**: Systematic testing of designs, copy, offers, pricing
- **Mobile Optimization**: Mobile-first design, fast loading, thumb-friendly interface
- **Conversion Rate Optimization**: Analyze data, identify bottlenecks, test improvements
- **Analytics Dashboard**: Track key metrics (conversion rate, AOV, cart abandonment)

## Workflow

1. **Baseline Analysis Phase**
   - Calculate current metrics (traffic, conversion rate, AOV, cart abandonment)
   - Analyze traffic sources (where do visitors come from?)
   - Review product page performance (which products convert best?)
   - Audit checkout flow (where do people drop off?)
   - Identify top traffic pages with low conversion

2. **Product Page Audit Phase**
   - Review titles (keyword-rich? compelling?)
   - Analyze product descriptions (feature/benefit focused?)
   - Check images (high quality? multiple angles?)
   - Review pricing display (clear? trustworthy?)
   - Assess social proof (reviews, ratings, testimonials)
   - Check CTAs (clear, prominent, compelling?)

3. **Checkout Flow Analysis Phase**
   - Map current flow (how many steps?)
   - Identify drop-off points (where do people leave?)
   - Review form fields (collect only essentials)
   - Check payment options (all major methods available?)
   - Assess trust signals (security badges, guarantees)
   - Test mobile experience (slow? hard to complete?)

4. **Conversion Bottleneck Identification Phase**
   - Identify top product pages with low conversion
   - Analyze why conversion is low (compare to high-converting pages)
   - List hypotheses for improvement
   - Prioritize by impact (effort Ãƒâ€” conversion lift potential)

5. **Test Design Phase**
   - Design 3-5 A/B tests (quick wins + strategic bets)
   - Quick wins: Improve images, rewrite title, add review social proof
   - Strategic bets: Redesign product page, simplify checkout
   - Define success metrics (conversion rate improvement)
   - Calculate sample size needed (statistical significance)

6. **Implementation Phase**
   - Launch A/B tests (equal traffic split, random assignment)
   - Run tests 2-4 weeks (control for seasonality)
   - Monitor metrics daily (detect issues early)
   - Analyze results (which variant won?)
   - Implement winning variant permanently

7. **Upsell Strategy Phase**
   - Identify product bundles (products often bought together)
   - Design product recommendations (on product page, in cart)
   - Create bundle offers (discount % for bundle)
   - Implement post-purchase upsells (thank you page)
   - Test messaging (impact on conversion)

8. **Continuous Optimization Phase**
   - Monitor metric trends (conversion rate, AOV, abandonment)
   - Run new tests (iterate on winners)
   - Scale winning changes (expand to other product pages)
   - Track ROI of changes (document results)

## Input Requirements
- **Store Platform**: Shopify, WooCommerce, custom, etc.
- **Current Metrics**: Traffic, conversion rate, AOV, cart abandonment rate
- **Product Catalog**: Number of products, price range, categories
- **Audience**: Who buys? Demographics, device types?
- **Goals**: Increase conversion? AOV? Reduce abandonment?
- **Analytics Access**: Google Analytics, Shopify, custom data available?

## Best Practices
1. **Mobile First**: 50%+ traffic is mobile (optimize there first)
2. **Test One Variable**: Only change one thing per test
3. **Statistical Significance**: Run long enough (200+ samples per variant)
4. **Continuous Testing**: Iterate constantly (new test each week)
5. **Margin Math**: AOV increase worth less than margin preservation
6. **Trust Signals**: Reviews, guarantees, security badges critical
7. **Friction Reduction**: Fewer form fields = higher conversion

## Edge Cases
- **Low Traffic**: A/B tests need 400+ samples (low traffic = slow testing)
- **High AOV Products**: Fewer transactions = small changes matter more
- **Inventory Issues**: Stock-outs kill conversion (communicate clearly)
- **Mobile-Specific**: Mobile conversion often 30-50% of desktop (prioritize mobile UX)
