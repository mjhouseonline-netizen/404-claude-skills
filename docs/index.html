Four simple steps

Install a skill in Claude

Upload the ZIP file without unzipping it.

  1. 01
    Download

    Choose a skill and click Download ZIP.

  2. 02
    Open Skills

    In Claude, go to Customize, then Skills.

  3. 03
    Upload

    Click +, Create skill, Upload a skill, then select the ZIP.

  4. 04
    Enable and test

    Turn the skill on and give Claude a matching task.

Use skills carefully

Check before you install

Skills can contain instructions and scripts. Review the source, install only what you need and never add passwords, private keys or sensitive personal information to a skill.
